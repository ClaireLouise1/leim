Show me

A adds 3 every time: the same jump, so it's linear (f(x) = 3x + 1, a straight line). B jumps 1, 3, 5: the jumps grow by the same amount (2), so it's quadratic (f(x) = x², a ∪ curve). C doubles every time: multiply by the same number, so it's exponential (f(x) = 2ˣ).

What is a function?

One input → one outputA function is a rule that gives each input exactly one output. Two inputs can share an output; one input can't have two.

f(x) = 3x + 2

f(x) notation

Find an outputf(x) = 3x + 2
f(4) = 3(4) + 2 = 14
f(−1) = 3(−1) + 2 = −1
Find an inputf(x) = 11
3x + 2 = 11
3x = 9, so x = 3

f(4) = 14 means the point (4, 14) is on the graph: x first, then y = f(x).

Reading a graph

  • f(x) = 0 (the roots): where the curve crosses the x-axis.
  • Turning point: the bottom of a ∪ (minimum) or the top of a ∩ (maximum). Write it (x, y).
  • f(x) = 5: go across from 5 on the y-axis to the curve, then down to the x-axis. A ∪ or ∩ curve usually gives two answers.
  • Estimate when the answer is between gridlines: say "about x = 3.4".

Linear, quadratic or exponential?

Graphs that tell a story

  • Straight line up: grows by the same amount each time (a taxi fare).
  • Flat: stays the same (one price all day).
  • ∩ curve: up, then down, with a maximum (a ball's height).
  • Exponential: slow, then faster and faster (doubling).

Higher Level

  • f(x) = g(x): where the two graphs meet. Read off the x values.
  • Exponential functions: f(x) = 3 × 2ˣ, so f(3) = 3 × 8 = 24.
  • Find k: if f(x) = x² + kx − 4 and f(2) = 6, then 4 + 2k − 4 = 6, so k = 3.
The classic mistakes: squaring a negative wrong ((−3)² is 9, not −9); writing a point (y, x); 2x and 2ˣ mixed up; joining a quadratic's points with straight lines instead of a smooth curve; giving one answer when the curve gives two; misreading the scale on the y-axis; checking a rule with the first column only.
Exam corner

Where this shows up in the exam

Functions come up in most papers: find f(3), draw a quadratic graph from a table, "use your graph to estimate", and graphs of real situations such as a ball's height. Higher Level can add where two graphs meet and exponential functions.

How marks are won and lost

  • Show the substitution: f(−2) = (−2)² − 2(−2) − 3.
  • Draw a smooth curve through the points, not straight lines between them.
  • Show your reading: draw the line across (or up) on the graph.
  • Give every answer: a quadratic often crosses a line twice.
  • In context, answer with units: "16 m after 2 s".

Try these exam-style questions

Written by Léim in the style of the exam (not taken from past papers). Try each one on paper first.

  1. A function. f(x) = 3x − 5. (a) Find f(4). (b) Find f(−2). (c) Find x when f(x) = 10.
    Show the worked answer

    (a) f(4) = 3(4) − 5 = 7.
    (b) f(−2) = 3(−2) − 5 = −6 − 5 = −11.
    (c) 3x − 5 = 10 → 3x = 15 → x = 5.

  2. A quadratic graph. This is the graph of f(x) = x² − 2x − 3 for −2 ≤ x ≤ 4.
    (a) Use the graph to solve f(x) = 0. (b) Write down the minimum point. (c) Use the graph to estimate the values of x for which f(x) = 2.
    Show the worked answer

    (a) The curve cuts the x-axis at x = −1 and x = 3.
    (b) The bottom of the curve: (1, −4).
    (c) Go across from 2 on the y-axis: the curve is there at about x = −1.4 and x = 3.4. (Any answer close to these gets the marks.)

  3. A ball. The graph shows the height h metres of a ball t seconds after it is thrown.
    (a) What is the greatest height? When is that? (b) When does the ball land? (c) When is the ball 15 m high?
    Show the worked answer

    (a) The top of the curve: 20 m, after 2 s.
    (b) h = 0 again at t = 4 s.
    (c) Go across at 15 m: it meets the curve twice, at 1 s (going up) and 3 s (coming down).

  4. Higher Level. The graphs of f(x) = x² − 2x − 3 and g(x) = x + 1 are shown.
    (a) Use the graphs to solve f(x) = g(x). (b) Check your answers with algebra. (c) Is h(x) = 2 × 3ˣ linear, quadratic or exponential? Find h(2).
    Show the worked answer

    (a) The graphs meet at (−1, 0) and (4, 5), so x = −1 or x = 4.
    (b) x² − 2x − 3 = x + 1 → x² − 3x − 4 = 0 → (x + 1)(x − 4) = 0 → x = −1 or x = 4 ✓
    (c) x is the power, so it's exponential. h(2) = 2 × 3² = 2 × 9 = 18.
