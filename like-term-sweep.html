Variables & expressions

Spot the pattern

Try some numbers. Fill in each row in your head (or on paper):

  • x = 2:  3x + 2x = 6 + 4 = 10  and  5x = 10
  • x = 7:  3x + 2x = 21 + 14 = 35  and  5x = 35
  • x = 2, y = 5:  3x + 2y = 6 + 10 = 16  but  5xy = 5 × 2 × 5 = 50

Why does 3x + 2x always equal 5x, but 3x + 2y is not 5xy? Is x + x the same as x²? Try x = 3.

Show me

3x + 2x is 3 lots of x plus 2 lots of x: 5 lots of x, whatever x is. Those are like terms. 3x and 2y are lots of different things (like 3 apples and 2 bananas), so they can't be added into one term: 3x + 2y stays as it is. And x + x = 2x, not x²: with x = 3, x + x = 6 but x² = 9.

The words

  • A variable is a letter that stands for a number that can change (x, n, t…).
  • An expression is made of terms joined by + and − signs. 4x² − 3x + 7 has 3 terms.
  • The coefficient is the number in front of the letter, sign included: in 4x² − 3x + 7, the coefficient of x is −3.
  • The constant is the term with no letter: 7.
  • Short ways to write things: 3 × n = 3n, n × n = n², a × b = ab, n ÷ 2 = n/2, and 1x is just x.

Collecting like terms

Like terms have exactly the same letters with the same powers: 3x and −5x are like terms; 3x and 3x² are not; xy and yx are (the order of the letters doesn't matter).

  • Simplify 5a + 3b − 2a + b. a terms: 5 − 2 = 3. b terms: 3 + 1 = 4. Answer: 3a + 4b. Each term takes the sign in front of it.
  • Simplify 2x² + 5x − x² − 8x + 3. x² terms: 2 − 1 = 1. x terms: 5 − 8 = −3. Answer: x² − 3x + 3. Adding never changes the power: x² + x² = 2x², not x⁴.

Words into algebra

  • "5 more than n" → n + 5. "5 less than n" → n − 5 (not 5 − n: start with n and take 5 away).
  • "Double n, then subtract 3" → 2n − 3. "Half of n" → n/2.
  • Tickets at €8 each plus a €3 booking fee for the order: n tickets cost 8n + 3. The fee is paid once, so it isn't multiplied by n.
  • Perimeter: add all the sides. A rectangle with length 2x + 1 and width x has perimeter 2(2x + 1) + 2x = 6x + 2.

Substitution (putting numbers in)

Swap each letter for its number, in brackets, then follow BIMDAS.

  • 5 − 2x when x = −3: 5 − 2(−3) = 5 + 6 = 11. Minus × minus = plus.
  • x² when x = −4: (−4)² = (−4) × (−4) = 16, not −16.
  • 3x² when x = −2: square first: (−2)² = 4, then × 3 = 12 (not (3 × −2)² = 36).
  • ab − b when a = −2 and b = 5: (−2)(5) − 5 = −10 − 5 = −15.
The classic mistake: 2x when x = 3 is 2 × 3 = 6, not 23. A number next to a letter always means multiply.
Exam corner

Where this shows up in the exam

Expressions are everywhere in the paper: "simplify" parts, "find the value when x = −2", writing an expression for a cost, an age or a perimeter, and then using it. Later questions on equations, patterns, functions and graphs all start from these skills, so a slip here can cost marks in several questions.

How marks are won and lost

  • Use brackets for negative numbers when you substitute: 2(−3)², not 2 − 3². It's where most marks go.
  • Each term keeps the sign in front of it when you collect like terms.
  • Don't mix unlike terms: 3x + 2y and x² + x can't be simplified any further. Leave them.
  • Show the line where you put the numbers in: it earns marks even if the final answer slips.
  • Check your expression with a number: if n = 2 tickets cost €19, does 8n + 3 give 19? Yes.

Try these exam-style questions

Written by Léim in the style of the exam (not taken from past papers). Try each one on paper first.

  1. Simplify. (a) 5x + 3y − 2x + y  (b) 4a² − 3a + a² + 7a − 2
    Show the worked answer

    (a) x terms: 5 − 2 = 3; y terms: 3 + 1 = 4. 3x + 4y.
    (b) a² terms: 4 + 1 = 5; a terms: −3 + 7 = 4; the constant stays. 5a² + 4a − 2.

  2. Find the value. a = −2 and b = 5. Find the value of (a) 3a + 2b  (b) a² − b  (c) 2ab − b²
    Show the worked answer

    (a) 3(−2) + 2(5) = −6 + 10 = 4.
    (b) (−2)² − 5 = 4 − 5 = −1.
    (c) 2(−2)(5) − (5)² = −20 − 25 = −45.

  3. Phone plan. Plan A costs €15 a month plus 10c for each text. (a) Write an expression for the monthly cost, in euro, of t texts. (b) Find the cost of 40 texts. (c) Plan B costs €20 a month with free texts. Which plan is cheaper for someone who sends 40 texts a month?
    Show the worked answer

    (a) 10c = €0.10, so the cost is 15 + 0.1t euro.
    (b) 15 + 0.1(40) = 15 + 4 = €19.
    (c) €19 is less than €20, so Plan A is cheaper (by €1).

  4. The garden. A rectangular garden has length 3x + 2 metres and width x − 1 metres. (a) Write the perimeter in its simplest form. (b) Find the perimeter when x = 4. (c) Explain why x can't be 1.
    Show the worked answer

    (a) 2(3x + 2) + 2(x − 1) = 6x + 4 + 2x − 2 = 8x + 2 metres.
    (b) 8(4) + 2 = 34 m. Check: the sides are 14 m and 3 m, and 14 + 3 + 14 + 3 = 34 ✓.
    (c) If x = 1 the width is 1 − 1 = 0 m, so there would be no garden. x must be bigger than 1.
