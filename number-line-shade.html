Inequalities

Spot the pattern

6 > 2 is true. Do the same thing to both sides:

  • Add 3 → 9 > 5
  • Subtract 10 → −4 > −8
  • Multiply by 2 → 12 > 4
  • Multiply by −1 → −6 > −2

Which one is no longer true? How could you fix it?

Show me

The last one: −6 is less than −2. Fix it by turning the sign round: −6 < −2. So an inequality works just like an equation, with one extra rule: multiply or divide both sides by a negative number and the sign flips.

The four signs

<less than
>greater than
≤less than or equal to
≥greater than or equal to

In words: at least 5 → x ≥ 5 · at most 5 → x ≤ 5 · more than 5 → x > 5 · under 5 → x < 5.

On a number line

x > 3Open dot: 3 is not included.
x ≤ 3Closed dot: 3 is included.
−1 ≤ x < 4Between: shade from dot to dot.

ℕ, ℤ or ℝ?

x < 4, x ∈ ℕℕ = 1, 2, 3 … Dots only: {1, 2, 3}.
x ≥ −2, x ∈ ℤℤ = whole numbers, negatives too. Dots, and … where they go on.
x ≥ −2, x ∈ ℝℝ = every number, decimals too. A shaded line.

Solving

Solve it like an equation: do the same to both sides.

4x − 3 ≤ 2x + 9
2x − 3 ≤ 9  (subtract 2x)
2x ≤ 12  (add 3)
x ≤ 6  (divide by 2)

Check with one number from the shading: x = 0 → −3 ≤ 9 ✓.

Whole-number answers

  • 2x + 1 < 9, x ∈ ℕ → x < 4 → {1, 2, 3}. (No 0: ℕ starts at 1.)
  • 2x + 3 > 8, x ∈ ℤ → x > 2.5 → smallest value 3.
  • −1 < x ≤ 3, x ∈ ℤ → {0, 1, 2, 3}: 4 values.

Higher Level Flip, double, fractions

5 − 2x > 11
−2x > 6  (subtract 5)
x < −3  (divide by −2: FLIP)
−1 < 2x + 3 ≤ 11  (do it to all three parts)
−4 < 2x ≤ 8
−2 < x ≤ 4
(x + 2)/3 ≥ 4
x + 2 ≥ 12  (× 3)
x ≥ 10

Don't want to flip? Move the x term to the side where it is positive instead: 5 − 2x > 11 → 5 − 11 > 2x → −6 > 2x → −3 > x.

Real life and graphs

🚕 €4 + €2 per km. You have €15. How far?
4 + 2k ≤ 15 → 2k ≤ 11 → k ≤ 5.5 → 5 km (whole km).
  • "Most" or "fewest" whole things? Round down for a limit (5.5 km → 5), up for a target (6.2 weeks → 7).
  • From a graph: find where the line crosses the level (say y = 5), then read which side of that x the line is below or above.
Exam corner

Where this shows up in the exam

Usually one part of an algebra question: solve, then show it on a number line or list the values in ℕ or ℤ. Sometimes it's the last step of a word problem.

How marks are won and lost

  • Show each step, one line each.
  • Number line: open or closed dot, correct direction, arrow if it goes on. Dots for ℕ and ℤ, a shaded line for ℝ.
  • Read the set: ℕ has no 0 and no negatives.
  • Higher Level: divide by a negative → flip the sign.
  • Word problems: answer in words, rounded the sensible way.

Try these exam-style questions

Written by Léim in the style of the exam (not taken from past papers). Try each one on paper first.

  1. Solve and show. (a) Solve 4x − 3 ≤ 2x + 9, x ∈ ℝ, and show the answer on a number line. (b) List the values of x if x ∈ ℕ.
    Show the worked answer

    (a) 2x − 3 ≤ 9 → 2x ≤ 12 → x ≤ 6. Number line: closed dot at 6, shaded to the left with an arrow.
    (b) {1, 2, 3, 4, 5, 6}. Check x = 6: 21 ≤ 21 ✓

  2. The gym. A gym charges a €25 joining fee and €12 per class. Aoife has €100. (a) Write an inequality in n, the number of classes. (b) What is the greatest number of classes she can do?
    Show the worked answer

    (a) 25 + 12n ≤ 100.
    (b) 12n ≤ 75 → n ≤ 6.25. Whole classes only: 6 classes. Check: 25 + 72 = 97 ≤ 100 ✓, but 7 classes cost 109.

  3. Higher Level (a) Solve 5 − 2x > 11, x ∈ ℝ. (b) List the values of x for which −2 < 3x + 4 ≤ 13, x ∈ ℤ.
    Show the worked answer

    (a) −2x > 6 → divide by −2 and flip: x < −3.
    (b) Subtract 4: −6 < 3x ≤ 9. Divide by 3: −2 < x ≤ 3. So {−1, 0, 1, 2, 3}.

  4. Higher Level Spot the mistake. Cian solved 7 − 3x ≥ 1. Line 1: −3x ≥ −6. Line 2: x ≥ 2. (a) Show that x = 3 does not work. (b) Which line is wrong, and why? (c) Give the correct answer.
    Show the worked answer

    (a) 7 − 9 = −2, and −2 ≥ 1 is false.
    (b) Line 2: dividing by −3 must flip ≥ to ≤.
    (c) x ≤ 2. Check x = 0: 7 ≥ 1 ✓
