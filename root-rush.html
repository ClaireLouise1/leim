Quadratic equations

Spot the pattern

Look at the roots and the equation. What do the roots add up to? What do they multiply to?

x² − 7x + 10 = 0
(x − 2)(x − 5) = 0
Roots: 2 and 5
x² − 3x − 4 = 0
(x + 1)(x − 4) = 0
Roots: −1 and 4
x² + 8x + 15 = 0
(x + 3)(x + 5) = 0
Roots: −3 and −5
Show me

The roots multiply to the last number (2 × 5 = 10, −1 × 4 = −4) and add up to the middle number with its sign changed (2 + 5 = 7, and the middle term is −7x). The sign in each bracket is the opposite of the root: root 2 → (x − 2), root −3 → (x + 3).

Solving in 3 steps

1. Make it = 0x² + 2x = 15
x² + 2x − 15 = 0
2. Factorise(x + 5)(x − 3) = 0
3. Each bracket = 0x + 5 = 0 → x = −5
x − 3 = 0 → x = 3

Check by putting each root back in: (−5)² + 2(−5) = 25 − 10 = 15 ✓

Two short cuts

No number termx² − 6x = 0
x(x − 6) = 0
x = 0 or x = 6
No x termx² − 49 = 0
x² = 49
x = 7 or x = −7

Never divide both sides by x: you lose the root x = 0.

Roots → equation

Roots 4 and −2
(x − 4)(x + 2) = 0
x² − 2x − 8 = 0

Word problems

  • Let x stand for the unknown (a width, a number, a time).
  • Make the equation: width x, length x + 3, area 40 → x(x + 3) = 40 → x² + 3x − 40 = 0.
  • Solve: (x + 8)(x − 5) = 0, so x = −8 or x = 5.
  • Reject the answer that can't be true: a length can't be negative, so x = 5 cm.

Higher Level

  • 2x², 3x², …: 2x² + x − 6 = 0 → (2x − 3)(x + 2) = 0 → x = 3/2 or x = −2.
  • The formula when it won't factorise: x = (−b ± √(b² − 4ac)) ÷ 2a. For x² − 4x − 3 = 0: a = 1, b = −4, c = −3, so x = (4 ± √28) ÷ 2 = 4.65 or −0.65 (2 d.p.).
  • Find k: if x = 3 is a root of x² + kx − 21 = 0, put x = 3 in: 9 + 3k − 21 = 0, so k = 4.
The classic mistakes: not making it = 0 first; moving a term without changing its sign; the wrong signs in the brackets; root 3 written from (x + 3); dividing by x and losing x = 0; only one answer for x² = 49; keeping a negative length; in the formula, −b when b is already negative, and dividing only part of the top by 2a.
Exam corner

Where this shows up in the exam

Quadratic equations come up in most papers: "solve" questions, "write an equation with these roots", and word problems about areas, numbers or a ball's height. A quadratic often appears as the last step of a longer question. Higher Level can add 2x², the formula and "find k".

How marks are won and lost

  • Show the factors: write (x + 5)(x − 3) = 0, then each root.
  • Give both roots. One root on its own loses marks.
  • Check by putting a root back in.
  • In a word problem, say which root you reject and why, and answer with units.
  • Formula answers: write the formula, the values of a, b and c, and round only at the end.

Try these exam-style questions

Written by Léim in the style of the exam (not taken from past papers). Try each one on paper first.

  1. Solve. (a) x² − 7x + 12 = 0 (b) x² + 2x − 15 = 0 (c) x² − 5x = 0 (d) x² − 49 = 0
    Show the worked answer

    (a) (x − 3)(x − 4) = 0, so x = 3 or x = 4.
    (b) (x + 5)(x − 3) = 0, so x = −5 or x = 3.
    (c) x(x − 5) = 0, so x = 0 or x = 5.
    (d) x² = 49, so x = 7 or x = −7.

  2. Roots. (a) Write a quadratic equation with roots 2 and −6. (b) x = 3 is a root of x² + kx − 21 = 0. Find k, then find the other root.
    Show the worked answer

    (a) (x − 2)(x + 6) = 0, so x² + 4x − 12 = 0.
    (b) Put x = 3 in: 9 + 3k − 21 = 0, so 3k = 12 and k = 4. Then x² + 4x − 21 = 0 → (x + 7)(x − 3) = 0, so the other root is x = −7.

  3. A garden. A rectangular garden is x m wide and (x + 5) m long. Its area is 84 m².
    (a) Show that x² + 5x − 84 = 0. (b) Solve the equation. (c) Find the perimeter of the garden.
    Show the worked answer

    (a) Area = length × width: x(x + 5) = 84, so x² + 5x = 84 and x² + 5x − 84 = 0.
    (b) (x + 12)(x − 7) = 0, so x = −12 or x = 7. A width can't be negative, so x = 7.
    (c) The garden is 7 m by 12 m: perimeter = 2 × (7 + 12) = 38 m.

  4. Higher Level. (a) Solve 2x² + x − 6 = 0. (b) Solve x² − 4x − 3 = 0, giving your answers to 2 decimal places. (c) A ball's height after t seconds is h = 30t − 5t² metres. When is the ball 40 m high?
    Show the worked answer

    (a) (2x − 3)(x + 2) = 0, so x = 3/2 or x = −2.
    (b) a = 1, b = −4, c = −3: x = (4 ± √(16 + 12)) ÷ 2 = (4 ± √28) ÷ 2, so x = 4.65 or x = −0.65.
    (c) 30t − 5t² = 40 → 5t² − 30t + 40 = 0 → t² − 6t + 8 = 0 → (t − 2)(t − 4) = 0: at 2 s (going up) and 4 s (coming down).
