1. What is a function?

A function gives each input exactly one output. Here f(x) = 3x + 2. Two inputs may share an output; one input can't have two.

2. f(x) notation

Find an outputf(x) = 3x + 2 → f(4) = 3(4) + 2 = 14
Find an inputf(x) = 11 → 3x + 2 = 11 → x = 3

f(4) = 14 means the point (4, 14) is on the graph. Squaring a negative: (−3)² = 9.

3. Linear, quadratic or exponential?

Linear 3x + 1
same jump
Quadratic x² − 4
jumps change evenly
Exponential 2ˣ
× same number

4. Reading a graph

f(x) = x² − 2x − 3

  • f(x) = 0: where it crosses the x-axis: x = −1 or x = 3.
  • Minimum point: the bottom of the ∪: (1, −4).
  • f(x) = 2: across from 2, then down: about x = −1.4 or x = 3.4.

5. Graphs that tell a story

Straight line up: the same amount each time. Flat: no change. ∩: up then down (a maximum). Exponential: slow, then faster and faster.

6. Higher Level

f(x) = g(x): where the graphs meet. Exponential: f(x) = 3 × 2ˣ, f(3) = 3 × 8 = 24. Find k: f(x) = x² + kx − 4, f(2) = 6 → 4 + 2k − 4 = 6 → k = 3.

Classic mistakes: (−3)² = −9 · (y, x) instead of (x, y) · 2x and 2ˣ mixed up · straight lines instead of a smooth curve · one answer when there are two.

E. Exam-style questions (show your work)

  1. A function. f(x) = 3x − 5. (a) Find f(4) and f(−2). (b) Find x when f(x) = 10.
  2. Draw a graph. f(x) = x² − 2x − 3. (a) Copy and complete the table for −2 ≤ x ≤ 4. (b) Draw the graph. (c) Use it to solve f(x) = 0 and to estimate where f(x) = 2.
  3. A ball. Its height is h = 20t − 5t² metres after t seconds. (a) Find h at t = 1, 2, 3. (b) What is the greatest height? (c) When does it land?
