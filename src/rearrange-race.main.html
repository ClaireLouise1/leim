Algebra fractions work exactly like number fractions: same bottom first, then add the tops.

Adding and subtracting fractions

x + 34 − x − 26

  • Never add the bottoms: ½ + ⅓ ≠ 2/5.
  • Put each top in a bracket. The minus sign multiplies the whole bracket.

Long division

Same steps as 156 ÷ 12: divide, multiply, subtract, bring down.

              x + 3
      ┌─────────────
x + 2 │ x² + 5x + 6
      −(x² + 2x)
        ───────
             3x + 6
           −(3x + 6)
             ──────
                  0
1. Dividex² ÷ x = x
2. Multiplyx(x + 2) = x² + 2x
3. Subtract5x − 2x = 3x. Bring down + 6.
4. Again3x ÷ x = 3. 3(x + 2) = 3x + 6. Remainder 0.

Check: (x + 3)(x + 2) = x² + 5x + 6 ✓

Exam corner

Where this shows up in the exam

Usually a part of an algebra question: write as one fraction, divide, or "make t the subject" and then use the new formula. Changing the subject also turns up inside real-life questions.

How marks are won and lost

  • Brackets round each top. Minus sign → change both signs.
  • One line per step when rearranging.
  • Long division: line up the like terms. Check by multiplying back.
  • Use the formula: rearrange first, then put in the numbers.

Try these exam-style questions

Written by Léim in the style of the exam (not taken from past papers). Try each one on paper first.

  1. One fraction. Write (x + 3)/4 + (2x − 1)/3 as a single fraction.
    Show the worked answer

    Common bottom 12: (3(x + 3) + 4(2x − 1))/12 = (3x + 9 + 8x − 4)/12 = (11x + 5)/12.

  2. Divide. Divide 2x² + 7x + 3 by x + 3.
    Show the worked answer

    2x² ÷ x = 2x. 2x(x + 3) = 2x² + 6x. Subtract: x + 3. x ÷ x = 1. 1(x + 3) = x + 3. Remainder 0. Answer: 2x + 1.
    Check: (2x + 1)(x + 3) = 2x² + 7x + 3 ✓

  3. The formula. v = u + at. (a) Make t the subject. (b) Find t when v = 25, u = 5 and a = 4.
    Show the worked answer

    (a) v − u = at, so t = (v − u)/a.
    (b) t = (25 − 5)/4 = 20/4 = 5.

  4. Higher Level (a) Write 3/(x + 2) − 1/(x − 1) as a single fraction. (b) V = πr²h. Make r the subject.
    Show the worked answer

    (a) (3(x − 1) − (x + 2))/((x + 2)(x − 1)) = (2x − 5)/((x + 2)(x − 1)).
    (b) V/(πh) = r², so r = √(V/(πh)).
