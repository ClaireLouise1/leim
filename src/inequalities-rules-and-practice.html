1. The four signs

<less than
>greater than
≤less than or equal to
≥greater than or equal to

at least 5 → x ≥ 5 · at most 5 → x ≤ 5 · more than 5 → x > 5 · under 5 → x < 5

2. On a number line

x > 3: open dot (3 not included)
x ≤ 3: closed dot (3 included)
−1 ≤ x < 4: shade from dot to dot

3. ℕ, ℤ or ℝ?

x < 4, x ∈ ℕ (1, 2, 3 …): dots only
x ≥ −2, x ∈ ℤ (negatives too): dots and …
x ≥ −2, x ∈ ℝ (every number): a shaded line

4. Solving

Just like an equation: do the same to both sides.

4x − 3 ≤ 2x + 92x − 3 ≤ 9 (subtract 2x) → 2x ≤ 12 (add 3) → x ≤ 6 (÷ 2)

Check with a number from your answer: x = 0 → −3 ≤ 9 ✓

5. Whole-number answers

2x + 1 < 9, x ∈ ℕ → x < 4 → {1, 2, 3}. ℕ starts at 1.
2x + 3 > 8, x ∈ ℤ → x > 2.5 → smallest value 3.
−1 < x ≤ 3, x ∈ ℤ → {0, 1, 2, 3}: 4 values.

6. Real life and graphs

€4 + €2 per km, €15 to spend: 4 + 2k ≤ 15 → k ≤ 5.5 → 5 km. Round down for a limit, up for a target. From a graph: find where the line crosses the level, then read which side is below or above.

7. Higher Level

5 − 2x > 11−2x > 6 → divide by −2 and FLIP: x < −3
−1 < 2x + 3 ≤ 11all three parts: −4 < 2x ≤ 8 → −2 < x ≤ 4
(x + 2)/3 ≥ 4× 3: x + 2 ≥ 12 → x ≥ 10
Classic mistakes: open and closed dots mixed up · 0 in an ℕ answer · a shaded line when x ∈ ℤ · forgetting to flip when dividing by a negative · rounding the wrong way in a word problem.
Exam tip: one step per line. On a number line, check three things: the dot (open or closed), the direction, and dots or a shaded line.
