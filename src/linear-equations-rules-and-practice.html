Linear equations

↗ Léim

Learning outcomes (2018 specification): AF.2c, AF.4, U.3. Play the game: leim.ie/balance-it.html

1. Keep it balanced

3x + 2 = 14
"=" means both sides have the same value. Do the same thing to both sides and it stays balanced.

2. Undo, last thing first

4x − 7 = 21
4x = 28 (+7 both sides)
x = 7 (÷4 both sides)
Check: 4(7) − 7 = 21 ✓

+ undoes −, × undoes ÷: x + 9 = 4 → x = −5; −3x = 18 → x = −6; x/4 = 5 → x = 20.

3. Letters on both sides

5x + 3 = 2x + 18
3x + 3 = 18 (−2x both sides)
3x = 15 → x = 5

A term that moves across the = changes its sign.

4. Brackets: expand first

3(x − 4) = 2(x + 1)
3x − 12 = 2x + 2 → x = 14

5. Fractions: clear them first

Multiply every term by the LCM of the bottom numbers.

x/2 + x/3 = 10 (LCM 6)
3x + 2x = 60 → 5x = 60 → x = 12

(x + 2)/5 = 3 → x + 2 = 15 → x = 13

Don't forget the number on its own: the 10 becomes 60.

6. Equations from words

Say what x stands for, write the other amounts using x, find what is equal, solve, then answer in words.

"I think of a number, multiply it by 4 and add 7. The answer is 31."
4x + 7 = 31 → 4x = 24 → x = 6

Consecutive numbers: x, x + 1, x + 2 · angles in a triangle: 180° · perimeter: add all the sides.

7. Always check

Put your answer into the original equation: both sides must give the same number.

Exam tip: show every step on its own line (method marks), do the same to both sides and to every term, and watch the signs when you expand a bracket or move a term. In word problems, say what x is and answer with units.
