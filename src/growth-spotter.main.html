Patterns 2: quadratic & exponential

Straight-line (linear) patterns are on Pattern Builder. Graphs of these functions are on Graph Match.

Spot the pattern

1 4 9 16 25 3 5 7 9 2 2 2

Row 2: 1st differences (the jumps). Row 3: 2nd differences (how the jumps change).

Now try these the same way. What changes by the same amount?

  • 2, 5, 10, 17, 26, …
  • 3, 6, 12, 24, 48, …
Show me

2, 5, 10, 17, 26: jumps 3, 5, 7, 9 → 2nd differences 2, 2, 2. Quadratic. (It's n² + 1.)
3, 6, 12, 24, 48: jumps 3, 6, 12, 24 — they double too! Each term is × 2. Exponential.

Three kinds of pattern

Linear5, 8, 11, 14
Same jump: +3 every time.
Graph: a straight line.
Quadratic3, 6, 11, 18
Jumps 3, 5, 7 → same 2nd difference (+2).
Graph: a curve (∪).
Exponential3, 6, 12, 24
Same multiplier: × 2 (doubling) or × 3 (tripling).
Graph: flat, then shoots up.

Next term of a quadratic: 3, 6, 11, 18, ? Jumps 3, 5, 7, so the next jump is 9. 18 + 9 = 27.

Growing tile patterns

Stage n = a square of n × n tiles + 2 yellow tiles. Count: 3, 6, 11, … Rule: n² + 2.
Stage 10 = 10 × 10 + 2 = 102. (Not 10 × stage 1!)

Stage n = n rows of (n + 1). Count: 2, 6, 12, … Rule: n(n + 1) = n² + n.

Doubling and tripling

1, 2, 4, 8, … each stage is × 2. Tripling: 1, 3, 9, 27, … each stage is × 3.

  • 🦠 Start 50, doubles every hour. After 3 hours: 50 × 2 × 2 × 2 = 50 × 2³ = 400.
  • Rules: 2, 4, 8, 16 → Tₙ = 2ⁿ.  3, 9, 27, 81 → Tₙ = 3ⁿ.
  • Don't mix them up: 2n (2, 4, 6, 8) ≠ n² (1, 4, 9, 16) ≠ 2ⁿ (2, 4, 8, 16).
  • Doubling starts slowly but in the end beats any linear pattern.

Higher Level Finding Tₙ = an² + bn + c

4, 11, 22, 37, … 1st differences 7, 11, 15. 2nd differences 4, 4 → 2a = 4, so a = 2.

  • Take away an². What's left is linear → bn + c.
  • "Which term is 211?" Solve 2n² + n + 1 = 211 → n = 10.
Exam corner

Where this shows up in the exam

A pattern question: a tile or matchstick picture, or a table. Continue it, say what kind of pattern it is (with a reason), and find a far-away term. Higher Level often asks for the general term.

How marks are won and lost

  • Show the differences (or the × number) as your reason. "It goes up" gets no marks.
  • Stage 10 ≠ 10 × stage 1. Use the rule.
  • Check your rule with two terms from the table.
  • Doubling: × 2 each step, not + 2.

Try these exam-style questions

Written by Léim in the style of the exam (not taken from past papers). Try each one on paper first.

  1. Tiles. The tile pattern in "Growing tile patterns" above has 3, 6, 11 tiles in stages 1, 2, 3. (a) How many tiles in stage 4? (b) Is the pattern linear, quadratic or exponential? Give a reason. (c) How many tiles in stage 10?
    Show the worked answer

    (a) Jumps 3, 5 → next jump 7. 11 + 7 = 18.
    (b) 1st differences 3, 5, 7; 2nd differences 2, 2 (the same). Quadratic.
    (c) Stage n = n² + 2, so 10² + 2 = 102.

  2. Two plans. Plan A: €100 in week 1, then €100 more each week (100, 200, 300, …). Plan B: €1 in week 1, doubling every week (1, 2, 4, …). (a) Find each amount in week 6. (b) In which week is Plan B first bigger than Plan A?
    Show the worked answer

    (a) A: 100 × 6 = €600. B: 1, 2, 4, 8, 16, €32.
    (b) B: 64, 128, 256, 512, 1024, 2048 (weeks 7–12). A: 700, … 1100, 1200. Week 11: 1024 < 1100. Week 12: 2048 > 1200. Week 12.

  3. Which is which? Three patterns: A: 4, 7, 10, 13, 16. B: 2, 5, 10, 17, 26. C: 3, 9, 27, 81, 243. Which one is linear, which quadratic and which exponential? Give a reason for each.
    Show the worked answer

    A: same jump +3 → linear.
    B: jumps 3, 5, 7, 9, 2nd differences 2, 2, 2 → quadratic.
    C: × 3 each time → exponential (tripling).

  4. Higher Level The pattern 4, 11, 22, 37, … is quadratic. (a) Find Tₙ in the form an² + bn + c. (b) Which term is 211?
    Show the worked answer

    (a) 2nd difference 4, so a = 2. Tₙ − 2n² = 2, 3, 4, 5 = n + 1. Tₙ = 2n² + n + 1.
    (b) 2n² + n + 1 = 211 → 2n² + n − 210 = 0 → (2n + 21)(n − 10) = 0 → n = 10 (n can't be negative). Check: 200 + 10 + 1 = 211 ✓
