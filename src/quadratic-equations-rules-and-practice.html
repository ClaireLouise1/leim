1. What is a root?

A root (or solution) is a value of x that makes the equation true. A quadratic (an x² equation) usually has two roots. Check a root by putting it in: x = 2 in x² − 5x + 6 = 0 gives 4 − 10 + 6 = 0 ✓

2. Solve in 3 steps

1. Make it = 0x² + 2x = 15 → x² + 2x − 15 = 0
2. Factorise(x + 5)(x − 3) = 0
3. Each bracket = 0x + 5 = 0 → x = −5 · x − 3 = 0 → x = 3

The roots multiply to the last number (−5 × 3 = −15) and add to the middle number with its sign changed (−5 + 3 = −2, middle term +2x).

3. Two short cuts

x² − 6x = 0 → x(x − 6) = 0 → x = 0 or x = 6
x² − 49 = 0 → x² = 49 → x = 7 or x = −7

Never divide by x: you lose x = 0.

4. Roots → equation

Roots 4 and −2 → (x − 4)(x + 2) = 0 → x² − 2x − 8 = 0

The sign in the bracket is the opposite of the root.

5. Word problems

x(x + 3) = 40 → x² + 3x − 40 = 0 → (x + 8)(x − 5) = 0. x = −8 or x = 5, but a length can't be negative: x = 5 cm. Always say which root you reject and why.

6. Higher Level

2x² …: 2x² + x − 6 = 0 → (2x − 3)(x + 2) = 0 → x = 3/2 or x = −2.
The formula: x = (−b ± √(b² − 4ac)) ÷ 2a. x² − 4x − 3 = 0: x = (4 ± √28) ÷ 2 = 4.65 or −0.65.
Find k: x = 3 is a root of x² + kx − 21 = 0 → 9 + 3k − 21 = 0 → k = 4.

Classic mistakes: not making it = 0 first · a term moved without changing sign · root 3 from (x + 3) · only one root for x² = 49 · keeping a negative length.
Exam tip: write the factors, then both roots, then check one by putting it back in. In a word problem, answer the question that was asked, with units.

D. Word problems and Higher Level

  1. A rectangle is x cm wide and (x + 4) cm long. Its area is 60 cm². Find x.
  2. The square of a positive number, plus 3 times the number, is 40. Find the number.
  3. Two whole numbers in a row multiply to 156. Find them.
  4. A ball's height is h = 25t − 5t² metres after t seconds. When does it land?
