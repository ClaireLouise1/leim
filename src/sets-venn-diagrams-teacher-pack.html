Sets & Venn diagrams

↗ Léim

Learning outcomes (2018 specification): N.5, U.4 (sets usually come up as a survey question with a Venn diagram)

Aims

By the end of the lesson students can describe a set by listing or by a rule, use the notation ∈, ∉, ⊂, #, ∅ and U, find A ∩ B, A ∪ B, A \ B and A′ for 2 and 3 sets, show sets on a Venn diagram, solve survey problems (including with x), and check whether the operations are commutative or associative.

In this pack

p.1 Teacher notes · p.2 Human Venn Diagram cards + rounds · p.3 Venn Dominoes (cut-up) · p.4 Wall poster · p.5 Worksheet: Error Hunt + exam-style questions · p.6 Answers. Level: 1st year (Higher and Ordinary), or 3rd-year revision. Time: about 60 minutes. You need two skipping ropes or hoops (or chalk/tape circles). All questions are original.

Procedure

5 minLead-in: Stand up if… "Stand up if you have a brother." Sit. "Stand up if you have a sister." Ask: who stood up both times? Who never stood up? How many students are in the room? Can we show all of that in one picture? Elicit two overlapping circles in a box.
12 minHuman Venn Diagram (p.2). Lay two overlapping rope circles on the floor and label them A and B. Give out the 16 number cards. Read a round's rules; students walk to the right region (or stand outside the circles, inside the "room" = U). Each region explains why they're there. After round 2, ask: what is A ∩ B? A ∪ B? Who is in A′? Introduce the symbols on the board as students say them.
8 minGuided discovery: counting. Board #A, #B, #(A ∩ B) and #(A ∪ B) for rounds 1–3 (from the key on p.6). Pairs look for the rule. Elicit #(A ∪ B) = #A + #B − #(A ∩ B) and why (the overlap is counted twice).
12 minVenn Dominoes (p.3), groups of 3–4. Start with START, work out the clue using the sets at the top of the page, find the domino with that answer on its left and build the chain to FINISH. Answer chain below.
8 minClass survey with x. Each pair asks 8 classmates two yes/no questions they choose (sport? instrument?), then fills a 2-set Venn diagram. Pairs swap totals only (how many asked, yes to Q1, yes to Q2, neither) and the other pair finds the overlap with x.
12 minWorksheet (p.5). Error Hunt in pairs (find the mistake, name the rule, fix it), then the exam-style questions alone. Feedback on question 3: why fill the middle first?
3 minExit ticket. A = {1, 2, 3, 4}, B = {3, 4, 5}: list A \ B and B \ A ({1, 2}; {5}). Homework: play Venn Sorter at leim.ie/venn-sorter.html (Survey sums round) and copy three lines from the "Go back over these" list.
Errors to look for: listing an element twice in A ∪ B · writing 0 for the empty set · forgetting to take the overlap away ("hurling only" = 15 instead of 15 − x) · putting "neither" inside a circle or leaving it out of the total · mixing up A \ B and B \ A · counting the centre as "exactly two". Support: colour each circle in a different colour. Fast finishers: is \ associative? Try (A \ B) \ C and A \ (B \ C) with A = {1, 2, 3, 4}, B = {2, 4, 6}, C = {4, 5, 6}.

B. Exam-style questions (show all your work)

  1. U = {1, 2, …, 10}, A = the factors of 10, B = the odd numbers in U. Draw a Venn diagram. List A ∩ B, A ∪ B, (A ∪ B)′ and B \ A.
  2. 31 students were asked about pets. 16 have a dog, 11 have a cat and x have both. Twice as many students have neither as have both. Draw a Venn diagram and find x.
  3. 60 café customers were asked what they ordered. (a) How many ordered none of the three? (b) How many ordered tea? (c) How many ordered exactly two? (d) Find #Scone.
  4. A = {1, 2, 3, 4}, B = {2, 4, 6}, C = {4, 5, 6}. (a) Is (A ∩ B) ∩ C = A ∩ (B ∩ C)? (b) Is (A \ B) \ C = A \ (B \ C)? Show your work.

B. Exam-style questions

  1. A = {1, 2, 5, 10}, B = {1, 3, 5, 7, 9}. A ∩ B = {1, 5}, A ∪ B = {1, 2, 3, 5, 7, 9, 10}, (A ∪ B)′ = {4, 6, 8}, B \ A = {3, 7, 9}.
  2. Dog only 16 − x, both x, cat only 11 − x, neither 2x. (16 − x) + x + (11 − x) + 2x = 31, so 27 + x = 31 and x = 4 (8 have neither).
  3. (a) 60 − 53 = 7 (b) 20 + 8 + 3 + 5 = 36 (c) 8 + 3 + 4 = 15 (d) 6 + 8 + 4 + 5 = 23
  4. (a) A ∩ B = {2, 4}, ∩ C = {4}; B ∩ C = {4, 6}, A ∩ {4, 6} = {4}: yes. (b) A \ B = {1, 3}, \ C = {1, 3}; B \ C = {2}, A \ {2} = {1, 3, 4}: no, set difference is not associative.

Marking tip

Give credit for each step, as the exam does: a correct Venn diagram with x in the right places earns marks even if the equation slips. Insist on set brackets and on ∅ for an empty set.
