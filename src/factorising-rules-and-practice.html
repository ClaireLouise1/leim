Factorising

Learning outcome (2018 specification): AF.3d. Play the game: leim.ie/factor-match.html

Factorising is expanding backwards: put the brackets back. Always check by multiplying out.

1. Highest common factor (HCF)

Find the biggest number and the letters in every term (smallest power). Put it outside; divide each term by it.

6x + 93(2x + 3)
4x² − 10x2x(2x − 5)
6ab + 9ac − 3a3a(2b + 3c − 1) (keep the 1)
HCF of 12x²y, 18xy²6xy

Fully factorised: nothing more can come out. 2(2x² − 5x) is not fully factorised.

2. Grouping (four terms)

xy − 3x + 2y − 6
= x(y − 3) + 2(y − 3)
= (y − 3)(x + 2)

A minus in front of the second pair: 2ab + 8a − 3b − 12 = 2a(b + 4) − 3(b + 4) = (b + 4)(2a − 3).

4. Difference of two squares

a² − b² = (a − b)(a + b)
x² − 49 = (x − 7)(x + 7)
2x² − 18 = 2(x² − 9) = 2(x − 3)(x + 3)
HL: 9x² − 4y² = (3x − 2y)(3x + 2y)
53² − 47² = 6 × 100 = 600

3. x² + bx + c

Find two numbers that multiply to c and add to b. x² + 8x + 12: pairs for 12:

1, 12 → 13
2, 6 → 8 ✓
3, 4 → 7
−2, −6 → −8

So x² + 8x + 12 = (x + 2)(x + 6).

Signs: c positive → both numbers have the sign of b. c negative → one +, one −.
x² − 9x + 14 = (x − 2)(x − 7)
x² + 2x − 15 = (x + 5)(x − 3)

Common factor first: 3x² + 15x + 18 = 3(x² + 5x + 6) = 3(x + 2)(x + 3)

Higher Level: ax² + bx + c. Try brackets that give the first and last terms; check the middle. 2x² + 7x + 3 → (2x + 1)(x + 3): middle 6x + x = 7x ✓. (2x + 3)(x + 1) gives 5x ✗.

Which method?

1. Common factor first, always. 2. Two terms, a minus, both squares → difference of two squares. 3. Three terms → x² + bx + c. 4. Four terms → grouping. Then check by multiplying out.

Exam tip: show the middle line in grouping, watch the signs (x² − x − 12 = (x + 3)(x − 4)), and check with x = 1: the question and your answer must give the same number.
