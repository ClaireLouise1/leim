Linear patterns & sequences

↗ Léim

Learning outcomes (2018 specification): N.4, AF.1a, AF.1b, U.4, U.11. Play the game: leim.ie/pattern-builder.html

1. The words

A sequence is a list of numbers in order: 5, 8, 11, 14, … Each number is a term: T₁ = 5, T₂ = 8. Tₙ is the nth term.

In a linear pattern you add (or take away) the same amount every time: the common difference. 5, 8, 11, … goes up by 3; 20, 16, 12, … by −4.

2. Finding Tₙ (the general term)

1. Find the common difference d: the rule starts dn.
2. Compare dn with T₁, then add or take away.
3. Check with T₂.

5, 8, 11, …: d = 3, so 3n. 3(1) = 3, but T₁ = 5: add 2. Tₙ = 3n + 2. Check: 3(2) + 2 = 8 ✓
30, 26, 22, …: d = −4. −4(1) = −4, T₁ = 30: add 34. Tₙ = 34 − 4n.

Not "n + 3": that only says how to get from one term to the next. Test it: n = 1 gives 4, not 5.

3. Picture patterns

Each new stage adds 2 matchsticks, and stage 1 has 3 = 2 + 1, so stage n has 2n + 1. Stage 10 has 21, not 10 × 3 = 30.

4. Far-away terms, working backwards

50th term of 5, 8, 11, …: 3(50) + 2 = 152 (or 5 + 49 jumps of 3).

Which term is 65? (65 − 5) ÷ 3 = 20 jumps after T₁, so it's T₂₁. Check: 3(21) + 2 = 65 ✓

Is 100 a term? (100 − 5) ÷ 3 = 31.66…, not whole, so no.

E. Exam-style questions (show your work)

  1. Tiles: stage 1 has 5 tiles, stage 2 has 8, stage 3 has 11. (a) Make a table for stages 1 to 5. (b) Find a formula for the number of tiles in stage n. (c) How many tiles are in stage 30? (d) Which stage uses 125 tiles?
  2. The sequence 50, 46, 42, 38, … (a) Find Tₙ. (b) Find T₁₀. (c) Which is the first term that is less than zero? Explain.
  3. Hannah's plant is 8 cm tall and grows 3 cm a week. (a) Write a formula for its height h after w weeks. (b) Find the height after 10 weeks. (c) After how many weeks will it be 50 cm? (d) On a graph of h against w, what are the start value and the rate of change?
