Linear patterns & sequences

Spot the pattern

A row of matchstick squares: 1 square uses 4 matchsticks, 2 squares use 7, 3 squares use 10. Fill in the next rows in your head (or on paper):

  • 1 square: 4  ·  3 × 1 + 1 = 4
  • 2 squares: 7  ·  3 × 2 + 1 = 7
  • 3 squares: 10  ·  3 × 3 + 1 = 10

How many for 4 squares? For 100 squares? Why is it "3 × the number of squares, + 1"? Where does the 3 come from, and where does the 1 come from?

Show me

Every new square needs 3 more matchsticks (a top, a bottom and one side), so the pattern goes up by 3 each time: that's the 3n. The very first square needs one extra stick for its left side, and that extra stick is only ever counted once: that's the + 1. So n squares need 3n + 1 matchsticks: 13 for 4 squares, 301 for 100 squares. (Not 100 × 4 = 400: the squares share their sides.)

The words

  • A sequence (pattern) is a list of numbers in order: 5, 8, 11, 14, … Each number is a term. T₁ is the 1st term, T₂ the 2nd, and Tₙ is the nth term.
  • In a linear pattern you add (or take away) the same amount every time. That amount is the common difference: 3 for 5, 8, 11, 14, … and −4 for 20, 16, 12, …
  • The general term (the rule) gives any term from its position n: Tₙ = 3n + 2 gives T₁ = 5, T₂ = 8, T₁₀ = 32.
  • In real life the common difference is the rate of change (€15 a week), and the value at the very start (week 0) is the start value.

Finding the general term Tₙ

  1. Find the common difference d. The rule starts dn.
  2. Compare dn with term 1, then add or take away to fix it.
  3. Check with term 2.
  • 5, 8, 11, 14, … The jump is 3, so start with 3n. When n = 1, 3n = 3, but T₁ = 5: add 2. Tₙ = 3n + 2. Check: 3(2) + 2 = 8 ✓
  • 30, 26, 22, 18, … The jump is −4, so start with −4n. When n = 1, −4n = −4, but T₁ = 30: add 34. Tₙ = 34 − 4n. Check: 34 − 8 = 26 ✓
The classic mistake: for 5, 8, 11, … writing "n + 3" because "it goes up 3". That only says how to get from one term to the next. Test it: n + 3 gives 4 for n = 1, not 5. The jump goes in front of the n: 3n + 2.

Far-away terms and working backwards

  • The 50th term of 5, 8, 11, …: use the rule, 3(50) + 2 = 152. (Or: term 1 plus 49 jumps of 3 = 5 + 147 = 152. It's 49 jumps, not 50.)
  • Which term is 65? Work backwards: 65 − 5 = 60 above term 1; 60 ÷ 3 = 20 jumps; so it's term 21. Check: 3(21) + 2 = 65 ✓
  • Is 100 in the pattern? (100 − 5) ÷ 3 = 31.66…, not a whole number, so no. (Term 32 is 98 and term 33 is 101.)

Tables and graphs

  • Put n in the top row of a table and Tₙ in the bottom row. In a linear pattern the bottom row goes up by the same amount each step.
  • Plot each pair (n, Tₙ) as a point: the points of a linear pattern lie on a straight line.
  • On a real-life graph, the start value is where the points meet the vertical axis (at 0), and the rate of change is how much the line goes up for each 1 across. Savings of €35 plus €15 a week: S = 15w + 35.
Exam corner

Where this shows up in the exam

Patterns are a favourite longer question: a picture pattern (matchsticks, tiles, dots) or a real-life situation, followed by a table to fill in, the next stages, a graph, the general term, and a "which stage…?" or "will it ever reach…?" part at the end. It links number, tables, graphs and algebra, so one question can carry a lot of marks.

How marks are won and lost

  • Fill in the table carefully: the later parts use it, so one slip early can cost several parts.
  • Always check your rule with two terms before you use it. A rule that only works for term 1 is wrong.
  • Don't just multiply stage 1: stage 10 is not 10 × stage 1 when there's an extra bit at the start.
  • Explain in words when asked: "it's linear because it goes up by 3 each time" / "the points lie on a straight line".
  • Show your working backwards for "which stage" questions: (100 − 1) ÷ 3 = 33, so stage 33.

Try these exam-style questions

Written by Léim in the style of the exam (not taken from past papers). Try each one on paper first.

  1. Matchstick squares. Stage 1 is 1 square (4 matchsticks), stage 2 is 2 squares in a row (7 matchsticks), stage 3 is 3 squares in a row (10 matchsticks). (a) How many matchsticks are needed for stage 4? (b) Write a formula for the number of matchsticks in stage n. (c) Which stage uses exactly 100 matchsticks? (d) Can any stage use exactly 50 matchsticks? Explain.
    Show the worked answer

    (a) It goes up by 3 each time: 10 + 3 = 13.
    (b) The jump is 3, so 3n; stage 1 has 4 = 3 + 1, so 3n + 1. Check: 3(2) + 1 = 7 ✓
    (c) (100 − 1) ÷ 3 = 99 ÷ 3 = 33, so stage 33. Check: 3(33) + 1 = 100 ✓
    (d) (50 − 1) ÷ 3 = 49 ÷ 3 = 16.33…, not a whole number, so no. (Stage 16 uses 49 and stage 17 uses 52.)

  2. The sequence 7, 11, 15, 19, … (a) Find Tₙ, the general term. (b) Find the 50th term. (c) Is 99 a term of the sequence? Is 101? Explain.
    Show the worked answer

    (a) Common difference 4, so 4n; 4 × 1 = 4 but T₁ = 7, so add 3: Tₙ = 4n + 3. Check: 4(2) + 3 = 11 ✓
    (b) T₅₀ = 4(50) + 3 = 203.
    (c) 99: (99 − 3) ÷ 4 = 24, a whole number, so yes, 99 is T₂₄ (4(24) + 3 = 99 ✓). 101: (101 − 3) ÷ 4 = 24.5, so no. (All the terms are odd, but that's not enough: you have to test it.)

  3. Seán's savings. Seán has €35 saved. He saves €15 every week. (a) Make a table of his savings for weeks 0 to 4. (b) Write down the start value and the rate of change. (c) Write a formula for his savings S after w weeks. (d) After how many weeks will he have €200?
    Show the worked answer

    (a) Weeks 0, 1, 2, 3, 4 → €35, €50, €65, €80, €95.
    (b) Start value €35 (week 0); rate of change €15 per week.
    (c) S = 15w + 35.
    (d) He needs €200 − €35 = €165 more; 165 ÷ 15 = 11 weeks. Check: 15(11) + 35 = 200 ✓

  4. Two patterns. Ella's pattern is 2, 5, 8, 11, … and Max's is 20, 22, 24, 26, … (a) Find the general term of each. (b) At which stage are the two patterns equal? Explain your method.
    Show the worked answer

    (a) Ella: 3n − 1. Max: 2n + 18.
    (b) At stage 1 the gap is 20 − 2 = 18. Ella goes up 3 each time and Max goes up 2, so the gap shrinks by 1 each stage. It reaches 0 after 18 more stages: stage 19. Check: 3(19) − 1 = 56 and 2(19) + 18 = 56 ✓
