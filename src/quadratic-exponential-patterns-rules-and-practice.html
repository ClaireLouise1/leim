Quadratic & exponential patterns

↗ Léim

Learning outcomes (2018 specification): AF.1a, AF.1b, AF.1c, N.4. Play the game: leim.ie/growth-spotter.html

1. Three kinds of pattern

Linear: 5, 8, 11, 14Same jump every time (+3). Graph: a straight line.
Quadratic: 3, 6, 11, 18Jumps 3, 5, 7 change by the same amount: same 2nd difference (+2). Graph: a curve.
Exponential: 3, 6, 12, 24Same multiplier: × 2 (doubling) or × 3 (tripling). Graph: flat, then shoots up.

2. Differences

1    4    9    16    25
   3    5    7     9      ← 1st differences
     2    2    2          ← 2nd differences

Next term of a quadratic: 3, 6, 11, 18, ? Jumps 3, 5, 7, so the next jump is 9: 18 + 9 = 27.

3. Growing tile patterns

Stage n = an n × n square + 2 yellow tiles: n² + 2. Stage 10 = 10 × 10 + 2 = 102. (Not 10 × stage 1.)

4. Doubling and tripling

1, 2, 4, 8, … × 2 each time. 1, 3, 9, 27, … × 3 each time.

Start 50, doubles every hour. After 3 hours?50 × 2 × 2 × 2 = 50 × 2³ = 400

Rules: 2, 4, 8, 16 → Tₙ = 2ⁿ. 3, 9, 27, 81 → Tₙ = 3ⁿ.
Don't mix up 2n (2, 4, 6, 8), n² (1, 4, 9, 16) and 2ⁿ (2, 4, 8, 16).

5. Higher Level: Tₙ = an² + bn + c

4, 11, 22, 37: 1st differences 7, 11, 15; 2nd differences 4, 4. a = half the 2nd difference = 2.

The last row is n + 1, so Tₙ = 2n² + n + 1. Check n = 2: 8 + 2 + 1 = 11 ✓
Which term is 211? 2n² + n + 1 = 211 → n = 10.

Classic mistakes: adding the same jump again in a quadratic · stage 10 = 10 × stage 1 · doubling as + 2 instead of × 2 · a = the 2nd difference (it's half) · 2n, n² and 2ⁿ mixed up.
Exam tip: always give a reason: write the differences (or the × number). Check any rule with two terms from the table.

F. Exam-style questions (show your work)

  1. Tiles. The pattern has 2, 6, 12 tiles in stages 1, 2, 3. (a) How many tiles in stage 4? (b) Linear, quadratic or exponential? Give a reason. (c) How many tiles in stage 10?
  2. Two plans. Plan A pays €50 a week (50, 100, 150, …). Plan B pays €1 in week 1 and doubles every week (1, 2, 4, …). In which week is Plan B first bigger than Plan A?
  3. Folding paper. Each fold doubles the layers: 1 fold → 2 layers. (a) Layers after 6 folds? (b) Fewest folds for more than 500 layers?
  4. Higher Level. 6, 15, 28, 45, … is quadratic. (a) Find Tₙ = an² + bn + c. (b) Which term is 231?
