1. Adding and subtracting fractions

Just like number fractions: same bottom first, then add the tops. 12 + 13 = 36 + 26 = 56

x + 34 − x − 26= 3(x + 3) − 2(x − 2)12 = 3x + 9 − 2x + 412 = x + 1312

Put each top in a bracket. The minus sign multiplies the whole bracket: −2 × −2 = +4. Never add the bottoms.

2. Long division

Divide, multiply, subtract, bring down. Same as 156 ÷ 12.

              x + 3
      ┌─────────────
x + 2 │ x² + 5x + 6
      −(x² + 2x)
        ───────
             3x + 6
           −(3x + 6)
             ──────
                  0

x² ÷ x = x · x(x + 2) = x² + 2x · subtract: 3x · 3x ÷ x = 3 · 3(x + 2) = 3x + 6 · remainder 0.
Check: (x + 3)(x + 2) = x² + 5x + 6 ✓

3. Changing the subject

Undo the steps in reverse order. y = 3x + 5:

x→× 3→+ 5→y
y→− 5→÷ 3→x   so x = y − 53
v = u + at → make t the subjectv − u = at → t = v − ua
y = (x + 4)/3 → make x the subjectA fraction? Multiply it away first: 3y = x + 4 → x = 3y − 4

4. Higher Level

3x + 2 − 1x − 1= 3(x − 1) − 1(x + 2)(x + 2)(x − 1) = 2x − 5(x + 2)(x − 1)
A = πr² → rr² = A/π → r = √(A/π) (square root last)
Subject twice: y = (x + 2)/(x − 3)xy − 3y = x + 2 → xy − x = 3y + 2 → x(y − 1) = 3y + 2 → x = 3y + 2y − 1
(x³ − 8) ÷ (x − 2)Write x³ + 0x² + 0x − 8 so nothing gets lost → x² + 2x + 4
Classic mistakes: adding the bottoms · not changing the sign of the second term after a minus · moving a number before multiplying away the fraction · dividing only one term · π outside the square root.
Exam tip: one step per line. After long division, multiply back to check. After rearranging, put in easy numbers to check both formulas agree.

E. Exam-style questions (show your work)

  1. One fraction, then solve. (a) Write (x + 3)/2 + (x − 2)/3 as a single fraction. (b) Hence solve (x + 3)/2 + (x − 2)/3 = 5.
  2. Divide, then solve. (a) Divide x² + 3x − 28 by x − 4. (b) Use your answer to solve x² + 3x − 28 = 0.
  3. The taxi. A taxi fare is C = 3.5 + 2k euro for k km. (a) Make k the subject. (b) A fare is €15.50. How far was the trip?
  4. Higher Level. E = ½mv². (a) Make v the subject. (b) Find v when E = 400 and m = 8.
